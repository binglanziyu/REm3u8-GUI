# 更新日志

本文件记录 REM-GUI 各版本的可见变化。格式参考 Keep a Changelog，版本号遵循语义化版本。

下载与二进制文件见 [Releases](https://github.com/binglanziyu/REm3u8-GUI/releases)。

## [未发布]

### 变更

- **自动补片上限放宽到 50%**：坏片补片的缺失率阈值由 30% 提高到 50%（`MaxPatchPercent`），缺口占比不超过一半时一律用相邻分片顶替补齐，超过 50% 才整组放弃并如实报错。
- **自动补片上限可调**：高级设置新增「补片上限」输入（缺失率 1–70%，默认 50%，配置键 `patchPercent`），可按需收紧或放宽自动补片的放弃阈值；越界值自动夹紧到合法区间，最高不超过 70%（缺失过半后邻片顶替会产生大量重复画面，再高只是把报错拖得更晚）。
- **暂停 / 继续**：「停止」改为「暂停」，暂停或失败后按钮变成绿色「继续」，点击直接续传，不再需要手动拖 `.resume.json`；成功后按钮收回「暂停」禁用态。
- **下载成功后只保留成品**：分片临时目录（含 raw.m3u8 等辅助文件）整树清理，混流成功后残留的同名分离轨文件（.m4s/.ts/.aac 等）一并删除，`.parts` 空目录收尾。

### 修复

- **失败判定增加产物兜底**：退出码 0 且引擎文案匹配不到失败信号时，再校验保存目录里确实生成了非空产物（仅解析不下载除外）；没有产物的“成功”一律按失败处理并保留续传，防止引擎换措辞后误删续传与分片。
- **命令预览与日志不再泄露密钥**：`--custom-hls-key / --custom-hls-iv` 的值在命令预览与日志里显示为 `********`，与配置打码口径一致。
- **高级设置输入不再丢失**：勾「显示明文」后编辑代理 / Header / KEY / IV，即使取消勾选再确定，改动也保留（原先会被旧值覆盖后静默丢弃）。
- **参数框提交闭环**：线程 / 重试 / 超时 / 限速输入后按回车或点其它地方即提交生效（规范化 + 越界夹紧回写 + 落配置），回车取消输入焦点；点击窗体空白、卡片、标签等非输入区也会退出编辑态。
- **关窗确认覆盖预检与安装**：预检或引擎下载安装进行中关窗也会弹确认，不再静默中断。
- **拖入内容无链接时明确反馈**：外部中转内容 / 拖入文本里解析不出链接时状态栏提示，不再无声丢弃。
- **Header / 附加参数框支持横向滚动**：超长行可横向查看（原生条已套暗色主题）。
- **状态语义统一**：停止按钮的红色不再在首次任务后永久丢失（改为「暂停」红字 / 「继续」绿字）；相关提示文案统一为“暂停”口径。

## [3.0.1] - 2026-11-14

本版为 v3.0.0 的缺陷修复版，重点解决三个会误导判断的问题：进度读数把容量当速率、混流与二进制合并的状态不同步、自动补片失败后被判成成功；同时补上任务收尾的存在感提示。

### 修复

- **进度读数：总大小被当成下载速率**
  收口帧 `2153/2153 100.00% 1.95GB - 00:00:00` 里的容量字段原先会被速率正则吃成 `1.95 GB/s`。现在速率只认带 `Bps` / `B/s` / `B/sec` 后缀的字段，容量单独按同一套单位、但不带速率后缀的规则解析（负向前瞻排除 `MBps` 这类速率）。引擎建连初期的 `0.00Bps` 占位值不再显示。
  主行改为「已完成/总数 百分比 · 共 总大小」，速率移到右侧独立一格，两者不再混排。分片计数到达 100% 时清空速率，完成后不再挂着最后一帧的瞬时速度。

- **混流与二进制合并不同步**
  勾选「混流为 MP4」时，引擎自己就会打开二进制合并（引擎日志：`你已开启下载完成后混流，自动开启二进制合并`），但界面与参数预览都还停在「没开」的样子。现在：
  - `--binary-merge` 在混流生效（未勾「跳过合并」、未勾「仅解析不下载」）时显式下发，参数预览与真实执行一致；
  - 高级选项里该项渲染为亮绿「（强制）」，点不掉，取消时提示"先取消混流为 MP4"；
  - 强制态不写进配置文件，避免用户下次取消混流后发现「二进制合并」莫名仍是勾着的。

- **自动补片失败仍报成功**
  失败判定原先在 `CompleteJob` 里直接读 `sawJobFailed`，而自动补片流程会把该标记清掉（补片本质是"重来一次"）。补片没能救回来时，退出码 0 就会被误判成功，并连带删掉续传文件与分片。现在先把本轮失败判定落到局部变量，再交补片流程，补片失败仍判失败。

- **失败原因文案**：区分「退出码 N」与「引擎报错（见日志）」，不再统一显示成退出码。

### 新增

- **任务完成提醒**
  - 日志区顶部弹出整宽横幅：成功绿、失败红、停止橙，常驻不自动消失（点击或开始下一次任务时收起）；停止横幅 6 秒后自动收起。
  - 进度条完成时满格并转为更亮的绿，与"下到一半"区分开。
  - 标题栏前缀同步为 `✔ 下载完成` / `✕ 下载失败` / `■ 已停止`，最小化或 Alt+Tab 时也能看出结果。
  - 任务栏按钮闪烁（`FlashWindowEx`，`FLASHW_TRAY | FLASHW_TIMERNOFG`），窗口切到前台后停止。
  - 开始新任务时复位横幅、标题、状态栏字重与进度条完成态。

### 文档

- `使用说明.txt` 同步进度行口径（容量与速率分列）、完成提示表现、混流触发强制二进制合并的说明。

### 内部

- `Theme` 增加强制开启态配色与 `Cursors.No`，与互斥锁定态区分。
- `Interop\Native` 增加 `FlashTaskbar`，异常按既有约定吞掉并记入日志。

## [3.0.0] - 2026-11-12

首个 C# WinForms 重建版，交付形态为单文件免安装。

### 新增

- 单 exe 交付：内嵌 `N_m3u8DL-RE` 与 FFmpeg，目标机无需安装 .NET SDK 与第三方组件。
- 默认保存目录为 exe 所在目录；分片暂存于 `保存目录\.parts\<文件名>`，任务完成自动清理，失败或中断保留以供续传。
- 断点续传：保存目录生成 `<文件名>.resume.json`，拖回窗口即可继续。
- 下载前智能预检、缺失分片自动补片（按缺失率 50% 判定），失败判定覆盖引擎自身的失败信号。
- 手动 AES-128 解密、并发下载（`-mt`）、混流为 MP4、跳过合并、仅解析不下载等高级参数。
- 程序自更新：内置更新清单 `update.json`，比对 GitHub 发布资产，支持镜像加速与 SHA256 校验。
- 高 DPI 适配、拖拽入队、命令行参数预览、运行日志与诊断日志分列。
